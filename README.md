### Information
This addon is bundled with the Project Lotus mod, and can be downloaded from the [latest release](https://github.com/Lotus-AU/LotusContinued/releases/latest) of Lotus.

LotusCosmetics makes use of [CorsacCosmetics](https://github.com/XtraCube/CorsacCosmetics) to add these cosmetics to the game as of version v1.8.0 of Lotus. 

LotusCosmetics bundles it's own version of CorsacCosmetics, so you do not need to install it separately, however you may if you see fit.

Finally, note that this repository does not contain the LotusCosmetics bundle file, so when building, please provide your own bundle file in the `/assets` folder named `LotusCosmetics.ccb`

---
### Adding your own Custom Cosmetics
As of v1.8.0 of Lotus, you are able to add your own custom cosmetics to the game. Instructions can be found [here](https://github.com/XtraCube/CorsacCosmetics#making-your-own-cosmetics). Please note that LotusCosmetics makes use of it's own cosmetics folder, in the `LOTUS_DATA/Cosmetics` directory, so you will need to place your custom cosmetics in that folder instead of the `CorsacCosmetics/Cosmetics` folder.

Adding your own custom cosmetics comes at the cost that only you will be able to see them, unless you send them to other players in your lobby.

If you wish to get your cosmetics added to the base mod, please reach out to us in our [discord server](https://discord.gg/projectlotus) and we will be happy to assist you.
